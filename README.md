# Finance Calculator

A simple command-line Python program that helps users make basic financial calculations.

## Description

The program gives the user two options:

- **Investment** – calculates how much an investment will be worth after a number of years, using either **simple** or **compound** interest.
- **Bond** – calculates the monthly repayment on a home loan, based on the value of the house, the annual interest rate and the number of months over which the loan will be repaid.

The user chooses an option from the menu, enters the required values, and the program prints the result.

## How to run

1. Make sure Python 3 is installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/example-repo.git
   cd example-repo
   ```
3. Run the program:
   ```bash
   python finance_calculator.py
   ```
